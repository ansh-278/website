# NAYAK // RESEARCH LAB

The production implementation of the site specified across Phases 1–7: a personal
research-portfolio site for a B.Sc. Physics undergraduate, built as a working
archive rather than a conventional portfolio.

## Stack

React 19, TypeScript, Tailwind CSS v4, React Router — set up with Vite.

## Getting started

```
npm install
npm run dev       # local dev server
npm run build     # type-checks, then builds to dist/
npm run preview   # serve the production build locally
npm run lint       # oxlint
```

## Project structure

```
src/
  types/content.ts     Content schema (Research, Project, Note, Timeline)
  content/              Content data — this is what you edit to add real content
    research.ts
    projects.ts
    notes.ts
    timeline.ts
  lib/                   Pure logic: reference-code generation, reading time,
                          field aggregation, the scroll-reveal hook
  components/
    ui/                   Design-system primitives (Button, Chip, Stage
                          Indicator, Section Block, Empty State, etc.)
    layout/               Nav, Footer, Page Header, page shell
    cards/                Research Card, Project Card, Notebook Entry row
  pages/                  One file per route
```

## Adding real content

This is the part that matters most: **you should never need to touch a
component to add a new entry.** Every page renders whatever is in
`src/content/*.ts` — add an object matching the shape in `src/types/content.ts`
and it appears everywhere it should (its index page, its field page if
tagged, the homepage's featured/recent sections) automatically.

- **A new Research investigation** → add an entry to `src/content/research.ts`.
  Leave `results`, `mathematicalFramework`, `computationalApproach`,
  `observations`, `limitations`, or `references` out entirely if you don't
  have them yet — the page shows an honest "pending" state instead of a
  placeholder that pretends to be real content.
- **A new Project** → add an entry to `src/content/projects.ts`. Same rule:
  leave `github`, `demo`, or `result` unset if they don't exist yet.
- **A new Note** → add an entry to `src/content/notes.ts`. Reading time is
  computed automatically from `content` — you don't set it by hand.
- **A Physics / Mathematics / Computation page never gets edited directly** —
  those three pages have no content of their own. They're generated by
  filtering Research + Projects + Notes by `category`. Tag an entry
  `category: "Physics"` and it shows up on the Physics page without any
  other change.
- **Reference codes** (`SRL·2026·PHY·003`) are computed from `date` +
  `category` + how many other entries share both — never type one in by
  hand.

## What's still a placeholder

Every placeholder in the current content is written as `[Placeholder — ...]`
so it's unmistakable in the rendered site, per the content-integrity rule
from Phase 6/7 — nothing here is invented to look more finished than it is.
Before this goes live, at minimum:

- Replace the placeholder Research, Project, and Note entries with real ones
  (or delete them once real entries exist)
- Add a real contact email in `src/pages/Contact.tsx`
- Add a real CV file and wire `CV_FILE_URL` in `src/pages/Resume.tsx`
- Fill in the Coursework/Skills sections on the Resume page
- Write the real About-page introduction in `src/pages/About.tsx`
- Fill in the four "current focus" lines in the homepage's Currently section
  (`src/pages/Home.tsx`)

## Known trade-offs (see the accompanying summary for full detail)

- Equations render as plain text in the math typeface for now — no LaTeX
  renderer is wired in yet, since there's no real equation content to
  justify the dependency.
- The `--color-text-tertiary` token was lightened from the originally
  specified `#5E6B78` to `#7C8894` to meet WCAG AA contrast at the small
  caption sizes it's used at throughout the system.
